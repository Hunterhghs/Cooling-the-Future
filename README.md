# Cooling the Future

**Climate Adaptation & Cooling Technology in the 21st Century** — a digital report by H Heuristics.

A single-page, long-form report examining cooling not as a consumer luxury but as core climate-adaptation infrastructure. Eight sections cover rising heat, the cooling access gap, the adaptation toolkit, governance and policy, frontier debates on direct climate intervention, regional case studies, and forward-looking scenarios for the century of heat.

## Structure

- `index.html` — the complete self-contained report (structure, design system, prose, and interactive charts inline).
- `.github/workflows/pages.yml` — GitHub Pages deployment via Actions.

## Deploy

The site is deployed to GitHub Pages from the `main` branch. The workflow in `.github/workflows/pages.yml` auto-deploys on every push. To enable it, set **Settings → Pages → Build and deployment → Source = GitHub Actions**.

Charts use [Chart.js](https://www.chartjs.org/) served from jsDelivr; all prose is self-contained with system-appropriate fallbacks.

## Sources

Data is drawn from WMO, Copernicus/ECMWF, IPCC AR6, IEA *The Future of Cooling*, SEforALL *Chilling Prospects*, the Lancet Countdown, ILO, and UNEP (see the footer's Sources &amp; methodology). Values labelled "approximate" or "indicative" are derived estimates or published ranges.
